# Yisi 图像工具

一个在浏览器本地完成多图拼接、单图编辑、轻量标注、格式转换与压缩的轻量工具。图片不会上传到服务器，关闭页面后队列会清空。

视频处理、独立裁剪、滤镜等能力暂未加入。

## 已实现

- 顶栏切换两个工作区：「拼接」把多张图片拼成一张；「单图编辑」逐张处理图片。两个工作区各有一份图片列表，切换时互不影响；标注、修瑕在两边都能用。上次用的工作区会保存。
- 单图编辑：可一次放进多张，点左侧列表或底部「上一张 / 下一张」切换；底部显示原图格式、尺寸和大小。修瑕计算期间不能切换图片（会提示），以免结果写不回去；切换图片后上一张的撤销记录会清空，标注本身保留。
- 导出先弹出对话框，拼接与单图共用：
  - 格式：PNG、JPG、WebP 互转（任何能读入的格式都能转成这三种）；单图导出 PNG / WebP 保留原图透明，JPG 按白底。
  - 压缩：JPG / WebP 可按质量（10–100%）或按目标大小（例如 500 KB 以内，自动找不超过它的最高质量）；最低质量仍超出时提示再缩小尺寸。PNG 是无损格式，只能靠缩小尺寸减小文件。
  - 尺寸：原尺寸、按百分比（5%–400%，可放大，用来留住 AI 清晰化多出的细节）或限定最长边（只缩不放）。
  - 对比预览：左边是未压缩的画面、右边是真实编码后的导出效果，拖动中线对比；可滚轮缩放（以指针处为中心）或按 − / + 逐级缩放（最大 800%），「适应」「100%」一键切换，放大后按住拖动平移、双击在适应与 100% 之间切换；同时显示输出尺寸、文件大小和相对原图的增减比例。
  - 单图模式可选「全部 N 张」按同一套设置批量导出：Chrome / Edge 下选一个文件夹逐张写入，同名文件不覆盖、自动加「 (2)」等序号；其他浏览器逐个下载。
  - 格式、质量、目标大小和缩小方式随设置保存。
- 一次选择多张图片，或把图片直接拖进窗口。
- 纵向、横向两种拼接方向，随时切换。
- 间距 0–200 px 可调，滑块和数字输入同步；数值随设置一起保存，下次打开沿用。
- 背景可选白、黑、透明或自定义颜色：图片大小不一时露出的空位和图片之间的间距都按它填充，预览实时更新，随设置一起保存。选透明时预览用棋盘格表示透明区域，导出 PNG / WebP 保留透明；JPG 不支持透明，「透明」按钮上会出现警示图标，导出时按白底填充并在结果提示里说明。
- 拖动卡片更换顺序，也支持键盘 `Alt + ↑/↓`。
- 不同尺寸图片自动居中对齐，预览实时更新。
- 预览支持滚轮缩放（从 50% 起，上限随图片数量自动提高，最多可把单张放大到占满视口）、放大后拖动查看；`+` / `-` 缩放、方向键平移、`0` 或双击恢复适应窗口。
- 缩略图放在点状画布之外：默认跟随拼接方向，纵向拼接时在画布右侧纵向排列，横向拼接时在画布上方横向排列；超出可用空间时按该方向滚动，固定尺寸不压缩。点击任意缩略图定位并放大到对应图片，左侧拼接队列卡片也可点击定位。删除队列中的图片会保留当前缩放，只有清空、从空恢复或整组替换时才回到适应窗口。
- 预览内可直接标注：文字、画笔、橡皮擦、局部修瑕；支持撤销 / 重做。标注是覆盖层，不会改写原图文件。
- 文字所见即所得：点击处出现的输入框就按最终字号和颜色显示，输入时可按住左侧手柄拖动位置；回车或点别处确认，Esc 取消。用「选择」工具点已有文字可重新打开修改内容、颜色和位置，清空内容即删除。
- 画笔、橡皮擦、修瑕选中后，鼠标处显示真实作用范围的圆圈，直径与落笔一致，随粗细和缩放变化。
- 清晰化（经典锐化）：标注栏「✦」按钮打开面板，有「轻度 / 标准 / 强」三个预设，也可拖强度（0–300%）、半径（0.8–5 px）、阈值（0–30）细调，改动后约 0.2 秒自动应用，在后台线程计算、页面不卡。拼接时作用于预览里选中的那张（点左侧卡片或把它移到画面中间），每张单独设置；单图编辑作用于正在编辑的那张。「还原」去掉这张的清晰化。清晰化结果参与预览、导出和之后的修瑕取样。
- AI 清晰化（仅 EXE 版）：清晰化面板切到「AI」，先选模型（内置 Real-ESRGAN General x4v3，或自己导入的模型），再选「结果」和等级。「结果」决定处理后保留几倍分辨率：原尺寸 / 2 倍（默认）/ 4 倍，模型做不到的倍数会置灰（倍数要能被模型的放大倍数整除，结果最多 4000 万像素）；保留 2 倍时导出把「尺寸」调到 200%，小字才会真的更清楚，导出对话框会提示。「保真」（默认）不缩小直接交给模型，文字和细节最稳，适合截图、文档；「增强」先缩到一半，重建得更多、快约 4 倍，适合模糊照片，但小字会变形。点「开始处理」前显示预计耗时（按这台电脑上次跑这个模型的速度估），处理中可点「停止」；在后台线程分块计算并显示进度，画布上的显示大小不变、标注不受影响，原图透明区域会保留。内置模型在设置页「清晰化」里下载（模型 4.6 MB，运行库 14.2 MB 与修瑕 AI 共用），也可在那里选默认的清晰化方式和默认模型。
- 自定义清晰化模型（仅 EXE 版）：设置页「清晰化 → AI 模型」点「导入模型…」选一个 `.onnx` 文件，程序把它复制到模型目录的 `custom` 文件夹（按 SHA-256 去重，原文件不动），之后可改名、设为默认、删除。要求：一个 float32 输入 [1, 3, 高, 宽]、RGB 取值 0–1，输出是输入的整数倍（×1–×8）；固定尺寸输入（如只收 64 × 64）会自动分块补边。第一次在面板里选它时会在后台试算一次，识别出放大倍数（面板显示「已识别：×2」）；不符合要求时显示原因，不能开始处理。导入的模型由你自己负责许可证（如 CC BY-NC 不能商用）。
- 前后对比：标注栏「对比」按钮打开后，画布上出现可拖动的中线（也可用左右方向键），左边是原图（不含清晰化、修瑕和标注），右边是处理后的样子；拼接和单图编辑都能用，放大、平移时照常对比。
- 局部修瑕：涂抹要去掉的物体（例如挡住栏杆的塑料袋），按周围画面补全被挡住的内容。两种补法各算一遍——「结构优先」统计画面里反复出现的位移（栏杆间距、砖缝、窗格），用图割把整段结构平移进洞里，再用泊松融合抹平颜色接缝；「平滑优先」按 7×7 小块相似度逐层细化，适合天空、渐变、曲面。默认采用与周围更连贯的结果，预览右下角可一键换成另一种。计算在后台线程进行，期间显示进度，页面不卡。
- 修瑕也可以改用 AI 模型（仅 EXE 版）：设置页「局部修瑕」并排列出三种方式的长处与代价——经典算法（无需下载，重复结构最准）、AI · MI-GAN（约 41 MB，快，不规则内容过渡自然）、AI · LaMa（约 213 MB，较慢，大块缺失与远景更连贯）。选 AI 时若模型还没下载会先询问；下载由本机程序完成，显示进度，可暂停后接着下、可删除，下完按 SHA-256 校验；模型目录默认在程序目录下的 `models`，可更改。模型下载期间或不可用时，修瑕自动用经典算法并提示原因。
- 预览画布铺满整个点状区域：放大、平移或空白页变宽时，内容一直画到画布边缘；「适应窗口」时四周仍留出一圈边距。
- 标注工具栏固定在点状画布上方、画布之外，不会遮挡图片；缩放栏（左下）浮在画布上，可按住左侧手柄拖到画布任意位置，双击手柄回到默认位置。标注栏、缩放栏、空白页尺寸面板和缩略图都能收起：收起后完全隐去（标注栏收起后画布随之变高），在预览标题栏右侧的「显示」开关里点对应项即可恢复（空白页开关只在队列里有空白页时出现）。位置和显示状态会保存；收起标注栏会把工具切回「选择」。
- 笔触粗细可拖动滑块或在旁边的数字框输入（2–30）；按住滑块时会显示一个实际粗细的预览圆点和像素值。
- 预览区图标按钮悬停即显示提示；点过一个按钮后移到其他按钮（或移回来）也会立即显示，不受浏览器原生提示「按下后暂停」的限制。
- 可在队列中插入空白页（默认 1200 × 800、白底），在预览里输入宽高或拖动右下角手柄调整；空白页超过其他图片时画布随之变宽（变高），其他图片在屏幕上保持原来的大小和位置，手柄始终跟着指针。空白页可排序、删除、导出，也可以和图片一样添加标注。
- 标注、空白页和拼接结果一起导出，按所选背景绘制；拼接图文件名带时间，单图沿用原文件名并换成新扩展名。
- Chrome / Edge 可选择保存位置，其他浏览器回退到默认下载目录。
- 导出成功或手动清空后，左侧保留最近一次队列快照，可一键恢复；取消保存不会清空队列。
- 清空队列前二次确认；导入失败、导出结果都有明确提示。
- 顶栏「设置」按类别分成三个页签：「预览缩略图」调整缩略图显示方向（跟随拼接 / 横向 / 纵向）、大小（小 / 中 / 大）和图片显示方式（完整显示长边 / 完整显示短边居中裁剪 / 拉伸填满），只影响缩略图，不影响拼接和导出；「局部修瑕」选择补全方式、下载 AI 模型、更换模型目录；「配置文件」查看或更换配置文件目录。页签可用左右方向键和 Home / End 切换；返回拼接再进设置时停在上次看的分类，重新打开程序回到第一个；配置未能保存、模型下载失败时，对应页签上显示警示图标。
- 设置（缩略图、间距、背景、修瑕补全方式、预览面板的位置与显示状态、工作区、导出格式与压缩设置）自动保存：EXE 版写入配置文件，默认放在程序所在目录，可在设置页「配置文件」里更换目录，更换后自动把配置文件移过去；浏览器开发模式保存在 localStorage。设置页底部的「恢复默认设置」对所有分类生效，会一并重置间距、背景（回到白色）、修瑕补全方式和预览面板的位置与显示状态，不改变配置目录，也不删除已下载的模型。
- 顶栏「关于」查看版本、运行方式、技术栈、功能范围、快捷键、项目地址、联系方式、隐私与已知限制；「项目与联系」里有点 Star 的邀请，以及提 Issue 的入口（GitHub / Gitee）。
- 关于页可立即检查更新；启动后自动检查（最多每 24 小时一次），托盘菜单也可检查。更新窗口显示下载进度，SHA-256 校验通过后重启安装。
- 全本地处理，不请求后端，不上传图片。

## 直接使用（免安装 EXE）

Windows 10 / 11 用户可以直接双击 `release\Yisi图像工具.exe`，不需要安装 Node.js 或 pnpm。程序会在本机启动只读页面服务，并自动用默认浏览器打开：

- 关闭浏览器后程序仍在系统托盘运行；双击托盘图标可重新打开，右键托盘图标可退出。
- 再次双击 EXE 会打开已运行实例的页面，不会启动第二份服务。
- 如果 47831 端口被占用，先在托盘退出旧实例再重试。
- 首次运行若出现 Windows SmartScreen 提示，点“更多信息”再点“仍要运行”。
- 依赖 Windows 自带的 .NET Framework 4.8；极少数精简系统若缺失需要先安装。
- 程序启动约 3 秒后会静默检查更新（距上次检查不足 24 小时则跳过）；发现新版本会打开更新窗口，下载、校验和安装都在这个窗口完成。也可以在关于页或托盘菜单手动检查。

- AI 修瑕模型默认下载到 EXE 同目录的 `models` 文件夹（修瑕用 MI-GAN 26.8 MB、LaMa 198.4 MB，清晰化用 Real-ESRGAN 4.6 MB，另有各模型共用的 onnxruntime-web 运行库 14.2 MB）；导入的自定义模型放在其中的 `custom` 子文件夹，清单是 `custom/custom-models.json`。在设置页「局部修瑕 → 模型目录」可换到其他目录，已下载和下了一半的文件会一起移过去，位置记在 EXE 同目录的 `yisi-image-tool.models-dir.txt`（不可写时同样改存 `%LOCALAPPDATA%\YisiImageTool`）。下载中断后再点「继续下载」会从断点续传。
- 设置保存在 EXE 同目录的 `yisi-image-tool.settings.json`，拷走程序时一起拷走即可沿用。在设置页「配置文件」点「更改目录…」会弹出系统选择目录窗口，选好后配置文件移到新目录，EXE 同目录留下 `yisi-image-tool.config-dir.txt` 记录位置；EXE 所在目录不可写（如放在 Program Files）时，位置记录改存到 `%LOCALAPPDATA%\YisiImageTool`。
- 首次运行 v0.9.0 时，会把旧版保存在浏览器里的缩略图设置迁移进配置文件，并删除浏览器里的旧副本。

本地服务只监听 `127.0.0.1:47831`，不对局域网开放，也不会上传图片。

## 开发运行

环境要求：Node.js 20 或更高版本，pnpm。

```bash
pnpm install
pnpm dev
```

打开终端里显示的地址即可使用。

Windows 下也可以双击 `启动工具.cmd`：脚本会检查 Node.js 和 pnpm，首次运行自动安装依赖，然后启动并打开浏览器。

## 构建与测试

```bash
pnpm test      # 运行布局、预览几何、标注、清晰化、导出格式与压缩、设置与浮动工具栏位置单元测试
pnpm build     # 类型检查 + 生产构建，产物在 dist/
pnpm preview   # 预览生产构建
```

### 构建 EXE

在 Windows 10 / 11 构建机上安装 Node.js、pnpm 后，双击 `构建EXE.cmd`，或执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/build-exe.ps1
```

脚本会依次完成生产构建、把 `dist/` 打包成 `launcher/WebAssets.zip`、用系统自带的 .NET Framework `csc.exe` 编译，产物为：

```text
release/
├── Yisi图像工具.exe
└── 使用说明.txt
```

`release/`、`launcher/WebAssets.zip` 是构建产物，不进入版本控制。

## 使用说明

1. 点击「选择图片」或直接把图片拖进拼接队列 / 预览区；需要留白时点队列底部「空白页」。
2. 在底部选择「纵向」或「横向」，拖动滑块调整间距；在「背景」里选白、黑、透明，或点「自定义」取任意颜色。
3. 拖动左侧卡片调整顺序；拖动时卡片会显示插入位置；点击卡片可定位并放大到预览中的对应图片。
4. 在预览区滚动鼠标滚轮缩放；图片多时继续放大，单张会逐渐占满视口。放大后可按住拖动查看；缩略图超出时按排列方向滚动，点缩略图可快速定位，点左下角「适应」恢复全图。
5. 图片发软时点标注栏的「✦」打开清晰化面板，选预设或拖滑块；点「对比」拖动中线看原图和处理后的差别。
6. 用画布上方的标注工具栏添加文字、画笔、橡皮擦或局部修瑕；文字在点击位置按最终样式输入、可拖动输入框，之后用「选择」工具点文字可再修改；画笔 / 橡皮擦 / 修瑕按住拖动，修瑕时把要去掉的物体整个涂满，松开后自动补全，不满意可点右下角「换成…」或撤销，撤销和重做在工具栏右侧。笔触粗细可拖滑块或直接输入数字。需要更大画布时点标注栏右端的收起按钮，之后在预览标题栏的「显示」开关里恢复；缩放栏挡住画面时可按住左侧手柄拖开，缩放栏、空白页面板和缩略图同样可以收起。选中空白页后，用尺寸面板或右下角手柄调整大小，其他图片不会跟着缩小。
7. 点右上角「导出图片」，在对话框里选格式、压缩方式和尺寸，看左边的对比预览和预计大小，满意后点「保存」；浏览器支持时选择保存位置。
8. 导出成功后会自动清空队列，并保留一条结果提示（点右上角关闭）；需要继续调整时，点左侧「恢复」取回刚才的图片、空白页、顺序和标注。
9. 点顶栏「设置」，在「预览缩略图」页签调整缩略图方向、大小和显示方式，在「局部修瑕」页签选择补全方式和下载 AI 模型，在「清晰化」页签选默认方式、下载或导入 AI 清晰化模型，在「配置文件」页签查看或更换配置文件的存放目录；点「关于」查看版本、快捷键、项目地址、联系方式和限制。点「返回拼接」（或「返回编辑」）回到工作区，队列和设置不会丢。
10. 要单独处理图片时，点顶栏「单图编辑」：把图片放进左侧列表，点哪张编辑哪张，同样可以标注、修瑕、清晰化；导出时选「当前这张」或「全部 N 张」，全部导出等于按同一设置批量转格式、批量压缩。

拼接规则：

- 纵向：画布宽度取最宽图片，所有图片水平居中，按队列顺序从上往下排列。
- 横向：画布高度取最高图片，所有图片垂直居中，按队列顺序从左往右排列。
- 间距只加在相邻图片之间，不会在画布四周留边。
- 空位和间距按底部「背景」填充，默认白色；背景选透明时，透明图片自身的透明区域在 PNG / WebP 里同样保留，JPEG 没有透明通道，按白底导出。
- 空白页有自己的白底，不跟随背景设置。

## 支持格式与限制

支持 JPG、PNG、WebP、GIF、AVIF、BMP。实际能否解码取决于当前浏览器，建议使用较新的 Chrome、Edge 或 Firefox。

- GIF 只导出当前解码到的第一帧，不保留动画。
- 单边超过 16,384 px，或总像素超过 1 亿时禁止导出，避免浏览器内存不足。
- 总像素超过 6,000 万时会提示尺寸较大，导出可能需要几秒。
- 所有图片都在内存中处理，图片特别多或特别大时请分批操作。
- 保存位置选择依赖浏览器的 File System Access API；Chrome、Edge 支持，Firefox 等会回退到默认下载目录。取消保存对话框不会清空队列。
- 导出格式按浏览器实际支持情况显示。对话框里每改一次设置都会重新编码一次来显示真实大小；拼接图很大时可能要 1–3 秒。
- 批量导出选文件夹依赖 File System Access API（Chrome、Edge）；其他浏览器逐个下载，首次可能弹出「允许下载多个文件」。
- 单图编辑切换图片会清空撤销记录；修瑕计算期间不能切换图片或工作区。
- 恢复快照只保留最近一次清空；导入新图不会立即释放快照，恢复、下一次清空或关闭页面时释放。图片很大时请留意内存占用。
- 刷新或关闭页面会清空队列和恢复快照，原图文件不受影响；设置会保留：EXE 版在配置文件里，浏览器开发模式在 localStorage 中（清除站点数据或换浏览器后恢复默认）。
- 更换配置目录时，若目标目录已有同名配置文件，会先备份为 `yisi-image-tool.settings.json.bak` 再覆盖；配置文件内容损坏时会改名为 `.corrupt-时间` 保留，并按默认值重建。
- 同时开多个页面修改设置时，以最后一次保存为准；其他页面刷新后才会看到新值。
- 缩略图在可用空间内按固定尺寸滚动，不随图片数量压缩；图片很多时请用滚动条或滚轮查看。
- 标注保存在当前页面的内存队列里，不会单独存成工程文件；导出时合并进 PNG / JPEG / WebP，清空队列后随恢复快照保留一次。
- AI 修瑕只在 EXE 版可用（浏览器开发模式下没有下载模型的本机程序）；首次下载需要联网，之后离线使用。本机实测 LaMa 每次约 7 秒（首次加载模型另需约 6 秒），加载后页面约占 600 MB 内存，空闲 3 分钟自动释放；MI-GAN 约 1 秒。配置较低的电脑会更慢。
- AI 清晰化同样只在 EXE 版可用。不会为了省时间暗中缩小图片（实测先缩到 1/4 时十几像素高的文字会变成一团色块），所以大图很慢：本机实测（Claude 桌面版内置浏览器，单线程）1554 × 942 的截图「保真」约 2 分钟，大约每百万像素 1.5 分钟；预计超过 90 秒时面板会提示改用「增强」或经典锐化。有的浏览器开多线程会卡住，程序发现模型加载 30 秒没有进展会自动改用单线程重跑，之后一直用单线程，第一次还要多等这 30 秒。AI 会重画细节，「增强」下小字可能变形，处理完请打开「对比」确认。保留 2 倍、4 倍分辨率时，这张图多占 4 倍、16 倍的画布内存。自定义模型的速度差别很大：实测文字专用的 Swin2SR ×2（clark-labs，7.6 MB，只收 64 × 64 输入）在用户截图的小字上比浏览器直接放大只锐利约 10%，也不会把字画坏，但比 Real-ESRGAN 慢约 3 倍（250 × 240 用 18.7 秒 对 5.9 秒），所以没有内置。真正糊掉的小字任何模型都补不回来。
- 局部修瑕用经典算法按周围画面补全：重复结构（栏杆、格栅、砖墙）和平坦背景效果最好；被挡住的是独一无二的内容（人脸、文字、复杂物体）时无法凭空还原，只能用相邻画面拼出近似内容，可换另一种补法或缩小涂抹范围重试。涂抹越大计算越久（常见 1–4 秒），超大区域会降低分辨率计算后再放大贴回。
- 画笔和修瑕的笔画提交后不能再单独选中或移动，只能撤销 / 重做整步操作；文字可以用「选择」工具点开重新修改。
- 清晰化只能让轻微发软的图更锐利，真正糊掉的细节补不回来；过强会出现白边、放大噪点。清晰化不进撤销记录，要去掉请点面板里的「还原」。左侧列表和缩略图仍显示原图。先修瑕再清晰化时，修瑕补上的那一块仍是未锐化的画面，建议先清晰化再修瑕。每张清晰化过的图片会多占一份原尺寸画布的内存。
- 空白页尺寸限制在 40–16,384 px；空白页和标注同样计入导出像素上限。
- 空白页改尺寸时预览会自动调整缩放来保持其他图片的屏幕大小；若所需缩放超过当前最大缩放，会停在最大值，其他图片略微变小。

## 隐私

应用没有远程后端，图片只通过浏览器 `File` / `Canvas` API 在本地读取和绘制。导出的图片由浏览器直接生成并下载。

EXE 版本只在本机 `127.0.0.1:47831` 提供静态页面、本地更新检查和配置文件接口（配置接口只接受本机页面带专用请求头的请求，别的网站无法替你改配置或移动文件）；检查更新时会读取 GitHub / Gitee 的 Release 信息并下载更新包，图片始终只在本地处理，不会上传。

只有在设置页点下载 AI 模型时，本机程序才会从公开镜像下载模型文件：MI-GAN / LaMa / Real-ESRGAN 依次尝试 `hf-mirror.com`、`huggingface.co`，运行库依次尝试 `registry.npmmirror.com`、`cdn.jsdelivr.net`、`unpkg.com`。下载地址固定到具体版本，下完按程序内置的 SHA-256 校验，不一致就删除；下载请求不带任何图片或个人信息。AI 计算同样在本机完成。导入自定义模型只在本机复制文件，不联网。

## 第三方组件与模型

- [onnxruntime-web](https://github.com/microsoft/onnxruntime) 1.31.1：MIT 许可，在浏览器里运行 AI 模型。
- [MI-GAN](https://github.com/Picsart-AI-Research/MI-GAN)（`migan_pipeline_v2.onnx`，来自 Hugging Face `andraniksargsyan/migan`）：代码与权重均为 MIT 许可。
- [LaMa](https://github.com/advimman/lama)（`lama_fp32.onnx`，来自 Hugging Face `Carve/LaMa-ONNX`）：Apache-2.0 许可。
- [Real-ESRGAN](https://github.com/xinntao/Real-ESRGAN) General x4v3（`realesr-general-x4v3.onnx`，来自 Hugging Face `jonathanst29/tinier-upscale-models` 的 ONNX 导出）：BSD-3-Clause 许可，用于 AI 清晰化。
- MI-GAN、LaMa 在 Places2 数据集上训练；所有模型文件都不随程序分发，由用户在设置页自行下载。用户导入的自定义模型同样不随程序分发，许可证由用户自行确认。
