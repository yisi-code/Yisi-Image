Yisi 图像工具（免安装版）

1. 双击 Yisi图像工具.exe。
2. 默认浏览器会自动打开拼接界面。
3. 关闭浏览器后程序仍在系统托盘运行：双击托盘图标可以重新打开，右键托盘图标可以退出。
4. 如果浏览器没有自动打开，请手动访问：
   http://127.0.0.1:47831/
5. 如果提示端口被占用，请先在托盘退出旧实例，再重新打开。
6. 首次运行若出现 Windows SmartScreen 提示，点“更多信息”再点“仍要运行”。

使用提示：
- 顶栏可切换「拼接」和「单图编辑」两个工作区，各有一份图片列表，互不影响。
- 拼接：点击「选择图片」或把图片拖进窗口，选择纵向/横向、调整间距和背景（白 / 黑 / 透明 / 自定义颜色）。
- 单图编辑：可一次放进多张，点左侧图片或底部「上一张 / 下一张」切换，逐张标注、修瑕、清晰化；修瑕计算中不能切换。
- 预览区滚轮缩放，图片多时也能继续放大到单张占满视口；放大后拖动查看，点左下角「适应」回到全图。
- 缩略图在点状画布外，默认跟随拼接方向：纵向在右侧、横向在上方；超出空间时按排列方向滚动，固定尺寸不压缩。点缩略图或左侧队列卡片可以定位并放大到对应图片；删除图片时保留当前缩放。
- 画布上方的工具栏可加文字、画笔、橡皮擦和局部修瑕；画笔 / 擦除 / 修瑕按住拖动，支持撤销和重做。标注只覆盖显示，不改原图文件。
- 文字输入时就按最终字号和颜色显示，可按住输入框左侧手柄拖动；回车确认、Esc 取消。用「选择」工具点已有文字可重新修改。
- 画笔、橡皮擦、修瑕选中后，鼠标处的圆圈就是实际作用范围。
- 局部修瑕：把要去掉的物体整个涂满，松开后按周围画面补全（栏杆、格栅等重复结构会被完整接上）。右下角可在「结构优先」「平滑优先」两种结果间切换；被挡住的是人脸、文字等独特内容时无法凭空还原。
- 修瑕也可以用 AI 模型：在设置页「局部修瑕」选择补全方式，页面会列出经典算法、AI · MI-GAN（约 41 MB，快）、AI · LaMa（约 213 MB，较慢，大块缺失更连贯）的区别。模型没下载时会先询问；下载显示进度，可暂停、继续、删除，下完自动校验。模型默认放在程序同目录的 models 文件夹，可在设置页更改。也可以在「局部修瑕 → AI 模型」点「导入模型…」选自己的 ONNX 修瑕模型（图像 + 遮罩两个输入、输出同尺寸图像），设为默认后修瑕就用它；第一次使用时自动识别格式，认不出时改用经典算法并说明原因。
- 清晰化：工具栏「✦」打开面板。经典锐化有轻度 / 标准 / 强预设和强度、半径、阈值滑块，拖动即生效；切到「AI」可选模型（内置 Real-ESRGAN 或自己导入的）重建细节；「结果」选保留原尺寸、2 倍（默认）或 4 倍分辨率，保留 2 倍时导出把「尺寸」调到 200% 小字才会更清楚；「保真」不缩小、文字最稳，适合截图；「增强」重建更多、快约 4 倍，适合模糊照片但小字会变形。点「开始处理」前会显示预计时间（大图可能要几分钟），处理中可点「停止」。AI 模型在设置页「清晰化」里下载（模型 4.6 MB + 运行库 14.2 MB）；也可点「导入模型…」选自己的 ONNX 超分模型（一个 [1,3,高,宽] 的 RGB 输入、输出为整数倍），会复制到模型目录的 custom 文件夹，可改名、设为默认、删除。「还原」去掉这张的清晰化。
- 工具栏「对比」打开后画布上出现可拖动的中线：左边原图，右边处理后。
- 标注工具栏固定在画布上方；左下角缩放栏可按住左侧手柄拖到别处（双击手柄复位）。标注栏、缩放栏、空白页面板和缩略图都能收起，收起后从画布隐去，在预览标题栏右侧「显示」开关里恢复；位置和显示状态会保存。
- 笔触粗细可拖滑块或在数字框输入 2–30，按住滑块时显示实际粗细的预览。
- 调整：标注栏选「调整」工具，拖选中图片的手柄缩放（勾「保持比例」时等比，可输入宽、高或百分比；不勾时可拉伸），「裁剪」后拖框调整再「确定裁剪」，「还原」回到原图；原图文件不变，标注跟着画面走。拼接时可切「单张 / 整张」，「整张」对整幅拼接结果缩放、裁剪、还原。
- 队列底部「空白页」可插入白底页；选中空白页后输入宽高，或拖动右下角绿色手柄调整大小，空白页变宽时画布随之变宽、其他图片不缩小；空白页可排序、删除和导出。
- 顶栏「设置」分四个页签：「预览缩略图」调整缩略图方向（跟随拼接 / 横向 / 纵向）、大小（小 / 中 / 大）和显示方式（完整显示长边 / 完整显示短边居中裁剪 / 拉伸填满）；「局部修瑕」选择补全方式、下载或导入 AI 模型；「清晰化」选默认方式和默认模型、下载或导入 AI 清晰化模型；已下载的模型点「查看文件」会打开它所在的文件夹；「文件管理」集中放配置文件目录和模型目录，可打开、更换或移回程序目录。页签上出现警示图标，表示这一类有错误要处理（如配置未能保存、模型下载失败）。
- 设置（缩略图、间距、背景、修瑕与清晰化方式、导出格式与压缩、工作区、预览面板位置与显示状态）保存在程序同目录的 yisi-image-tool.settings.json，拷走程序时一起拷走即可沿用；可在设置页「文件管理」点「更改目录…」换到其他目录，配置文件会自动移过去。
- 点「导出图片」先打开导出对话框：PNG / JPG / WebP 互转，JPG / WebP 可按质量或目标大小压缩，可按百分比缩放（最多 400%）或按最长边缩小；左边预览默认只显示导出效果，点「前后对比」才和未压缩的画面拖中线对比；可滚轮缩放，显示导出后的大小。拼接只放一张图也能导出。超出浏览器画布上限的大图导出 PNG 时分块编码，没有尺寸上限；JPG、WebP 受格式上限，超出时会提示改用 PNG。单图编辑可选「全部 N 张」按同一设置批量导出（选文件夹，同名不覆盖）。标注、清晰化和空白页会合并进导出图。拼接导出后队列自动清空，结果提示会保留，点右上角关闭；点左侧「恢复」可以取回图片、空白页和标注。
- 顶栏「设置」调整缩略图、修瑕、清晰化与配置文件；「关于」查看版本、运行方式、技术栈、快捷键、项目地址、联系方式、隐私与限制；「返回拼接」或「返回编辑」回到工作区。
- 关于页「立即检查更新」可手动检查；程序启动后也会自动检查（最多每 24 小时一次），托盘菜单同样可以检查。下载进度、SHA-256 校验和安装确认在更新窗口中完成，安装后自动重启。
- 图片只在本地处理，不会上传；刷新或关闭页面会清空队列和恢复快照。只有点下载 AI 模型（MI-GAN / LaMa / Real-ESRGAN）时才会联网下载模型文件（hf-mirror.com / huggingface.co，运行库来自 npm 镜像），下载内容按 SHA-256 校验。
- 觉得好用，欢迎到 GitHub / Gitee 给项目点个 Star，点星的人多了才更有动力开发更多功能；有需求或想法，可以在仓库提 Issue，或用关于页里的联系方式联系开发者。

系统要求：Windows 10 / 11，系统自带 .NET Framework 4.8。
