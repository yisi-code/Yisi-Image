Yisi 图像工具（免安装版）

1. 双击 Yisi图像工具.exe。
2. 默认浏览器会自动打开拼接界面。
3. 关闭浏览器后程序仍在系统托盘运行：双击托盘图标可以重新打开，右键托盘图标可以退出。
4. 如果浏览器没有自动打开，请手动访问：
   http://127.0.0.1:47831/
5. 如果提示端口被占用，请先在托盘退出旧实例，再重新打开。
6. 首次运行若出现 Windows SmartScreen 提示，点“更多信息”再点“仍要运行”。

使用提示：
- 点击「选择图片」或把图片拖进窗口，选择纵向/横向并调整间距。
- 预览区滚轮缩放，图片多时也能继续放大到单张占满视口；放大后拖动查看，点左下角「适应」回到全图。
- 缩略图在点状画布外，默认跟随拼接方向：纵向在右侧、横向在上方；超出空间时按排列方向滚动，固定尺寸不压缩。点缩略图或左侧队列卡片可以定位并放大到对应图片；删除图片时保留当前缩放。
- 预览左上角工具栏可加文字、画笔、橡皮擦和局部修瑕；画笔 / 擦除 / 修瑕按住拖动，支持撤销和重做。标注只覆盖显示，不改原图文件。
- 标注工具栏和左下角缩放栏可按住左侧手柄拖到别处（双击手柄复位）。标注栏、缩放栏、空白页面板和缩略图都能收起，收起后从画布隐去，在预览标题栏右侧「显示」开关里恢复；位置和显示状态会保存。
- 笔触粗细可拖滑块或在数字框输入 2–30，按住滑块时显示实际粗细的预览。
- 队列底部「空白页」可插入白底页；选中空白页后输入宽高，或拖动右下角绿色手柄调整大小，空白页变宽时画布随之变宽、其他图片不缩小；空白页可排序、删除和导出。
- 顶栏「设置」可调整缩略图方向（跟随拼接 / 横向 / 纵向）、大小（小 / 中 / 大）和显示方式（完整显示长边 / 完整显示短边居中裁剪 / 拉伸填满）。
- 设置（缩略图、间距、预览面板位置与显示状态）保存在程序同目录的 yisi-image-tool.settings.json，拷走程序时一起拷走即可沿用；可在设置页「配置文件」点「更改目录…」换到其他目录，配置文件会自动移过去。
- 导出时可在底部选择 PNG / JPG / WebP，并选择保存位置；标注和空白页会合并进导出图。导出后队列自动清空，结果提示会保留，点右上角关闭；点左侧「恢复」可以取回图片、空白页和标注。
- 顶栏「设置」调整缩略图；「关于」查看版本、运行方式、技术栈、快捷键、项目地址、联系方式、隐私与限制；「返回拼接」回到工作区。
- 关于页「立即检查更新」可手动检查；程序启动后也会自动检查（最多每 24 小时一次），托盘菜单同样可以检查。下载进度、SHA-256 校验和安装确认在更新窗口中完成，安装后自动重启。
- 图片只在本地处理，不会上传；刷新或关闭页面会清空队列和恢复快照。

系统要求：Windows 10 / 11，系统自带 .NET Framework 4.8。
